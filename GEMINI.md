# Project Strategy: Main Paper Back-to-School Map (Vuelta al Cole)
- **Role**: Senior UI/UX Architect & Frontend Developer.
- **Rules**: 
  1. **Planning First**: Before executing complex features (like Mapbox integration or Sweepstakes logic), always break down the task into atomic steps.
  2. **Visual Consistency**: Strictly follow the Mario-style/Board-game aesthetic. Use vibrant colors (Red #e52521, Blue #5c94fc, Yellow #f8d878), thick black borders (#222), and blocky shadows.
  3. **Core Features**: 
     - Interactive Map (Mapbox/Simulated Board).
     - Store filtering and search.
     - Main Paper Sweepstakes QR code integration.
  4. **Font**: Use 'Fredoka' for a playful, rounded, game-like typography.
